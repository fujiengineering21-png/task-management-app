# TaskBoard モック（画面イメージの確認用）

[画面設計](../docs/画面設計.md) をもとに、画面の見た目と操作の感じを確かめるための**使い捨てのモック**です。
本物のアプリは、技術選定のあとに作り直します。

## 開き方

`mock/index.html` をダブルクリックして、ブラウザ（Chrome・Edge・Safari）で開きます。サーバーの準備はいりません。

## 自分で検証するとき

`mock/guide.html` を開きます（モック用パネルの「検証ガイドを開く」からも開けます）。機能の全体像・仕組み（からくり）・52項目のチェックリスト・理解度チェックがあり、チェックの結果は「結果をコピー」でまとめて Claude に送れます。記録はそのブラウザにだけ保存されます。

## 確認できること

| 画面 | 試せる操作 |
|---|---|
| S-01 ボード画面 | タブで「仕事」「プライベート」を切り替える／タブをダブルクリックして名前を変える／カードをドラッグして移動・並び替え／○ をクリックして完了マーク／カラムの「⋯」から優先度順・期限順に整列／「ラベルで絞り込み」で複数選んで絞り込む |
| S-02 タスク作成モーダル | カラム下の「＋ タスクを追加」から開く。タイトルが空だと「作成」を押せない |
| S-03 タスク編集モーダル | カードをクリックして開く。「カラム」を変えて保存すると、移動先の一番下に入る |
| S-04 タスク削除確認 | 編集モーダルの「削除」から開く |
| S-05 ラベル管理 | 右上の「ラベル管理」から開く。色・名前は変えるとすぐ保存される |
| S-06 ラベル削除確認 | ラベル管理の 🗑 から開く。何件のタスクから外れるかが出る |

右下の **🛠 モック用パネル**（本物のアプリにはない）で、次の表示も確認できます。

- 画面の状態：通常／読み込み中／サーバーに接続できない
- 保存を失敗させる：D&D やチェックが元に戻る動き、モーダルにエラーが出る動き
- 見本データに戻す

## モックで省いているもの

- サーバーとデータベース。データはブラウザの JavaScript の中だけにあり、**再読み込みすると見本データに戻ります**
- タブに戻ったときの最新データの読み込み、毎日のリセット、書き込みの回数制限
- スマホの指での D&D
- 自動テスト
